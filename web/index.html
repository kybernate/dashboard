Enter a Kubernetes bearer token. The dashboard acts with this token, so Kubernetes RBAC decides what you can see and change.

How do I get a token?

Create a ServiceAccount with access to the GPU inventory and request a token for it:

kubectl -n kybernate-system create serviceaccount gpu-admin
kubectl create clusterrolebinding gpu-admin \
  --clusterrole=kybernate-editor \
  --serviceaccount=kybernate-system:gpu-admin
kubectl -n kybernate-system create token gpu-admin --duration=8h

kybernate-editor may reserve GPUs, kybernate-viewer may only look.
